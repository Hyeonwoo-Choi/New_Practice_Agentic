# 8. 회상과 자기 말로 설명하기

## 회상 (이 단원 이전의 내용 다시 꺼내기)

U01 은 첫 단원이라, 앞서 읽은 **보충 단원 S2 (async/await)** 를 회상합니다. S2 를 다시 열지 말고 먼저 답해 보세요.

1. `ask()` 안에서 `chat()` 앞에 `await` 가 없으면, 그 다음 줄의 `reply.content` 는 무엇일까?
2. `ask()` 를 부르는 쪽에서도 `await` 가 필요한 이유는? (`ask` 는 무엇을 돌려주는 함수인가?)
3. `async` 함수가 던진 오류는 어디서 잡히나?

답이 막히면 S2 를 열어 확인하세요. 확인한 뒤에 다시 한 번 자기 말로 써 보세요. (다음 단원들부터는 **2~3단원 전** 개념을 회상 문제로 섞습니다.)

## 자기 말로 설명하기

[reflection.md](reflection.md) 를 채우세요. 검사가 통과해도 이 칸이 비어 있으면 진도 화면에서 "회고: 아직" 으로 남습니다.

### 좋은 설명의 기준 (루브릭)

각 칸에서 아래를 확인하세요. **스스로 점검하는 용도**입니다.

| 기준 | 질문 |
|---|---|
| 용어 | `messages`, `role`, `assistant` 를 정의했는가? |
| 이유 | "왜 그렇게 되는가" 를 썼는가? (무엇을 한다 + 왜) |
| 없을 때 | 그것이 없으면 어떤 일이 생기는지 썼는가? |
| 예시 | 이 프로젝트의 구체적 예(스터디룸 질문)를 하나 들었는가? |
| 내 말 | 문서 문장을 복사하지 않았는가? |

### AI 에게 점검받고 싶다면 (정답 판정이 아니라 피드백입니다)

아래를 복사해서 reflection.md 내용과 함께 붙여 넣으세요.

```
아래는 내가 쓴 설명이다. 정답을 알려 주지 말고, 다음 기준으로 빠진 부분과 부정확한 부분만 지적해 줘.
기준: 용어 정의, 이유, 없을 때의 문제, 구체적 예시, 내 말로 썼는가.
틀린 문장은 왜 틀렸는지 질문 형태로 알려 줘. 고쳐 쓴 문장은 주지 마.
[여기에 reflection.md 붙여넣기]
```

AI 의 피드백도 틀릴 수 있습니다. 헷갈리면 `03-concept.md` 와 실행 기록으로 직접 확인하세요.
