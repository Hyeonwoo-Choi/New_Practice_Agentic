# 전체 커리큘럼과 예상 시간

한 단원 = **새 핵심 개념 1개**, 목표 30~45분(필수 경로), 직접 쓰는 코드 약 20줄.
시간은 모두 **추정**입니다. 사람이 푼 측정값은 U01 [FEEDBACK.md](../units/u01-messages/FEEDBACK.md) 부터 모입니다. 자동 테스트가 도는 시간은 학습 시간이 아닙니다.

| 단원 | 새 개념 (하나) | 선수 단원 | 핵심 구현 | 완료 기준 (동작) | 필수 경로 | 상태 |
|---|---|---|---|---|---|---|
| U00 | 진단 + 보충 S1~S3 | — | — | 진단 문제를 풀고 필요한 보충을 읽음 | 30분 | **제공됨** |
| **U01** | 모델은 기억하지 않는다 (messages) | U00 | `newConversation`, `ask`, 사용자별 대화(응용) | 후속 질문에 지난 대화를 보낸다. 대화가 섞이지 않는다 | 45분 | **견본 제공됨** |
| U02 | 도구 설명 ≠ 요청 ≠ 실행 | U01 | 도구 정의, 요청을 읽어 실제 함수 실행, `tool` 메시지 | 방 검색 도구 요청에 따라 실제 함수가 실행되고 결과가 다음 호출에 전달된다 | 40분 | 계획 |

## 시간 합계 (단원 구성 후 합산)

| 구분 | 계산 | 합계 |
|---|---|---|
| 필수 경로 (U00~U12, U14. U13 제외) | 30+45+40+40+40+45+40+35+45+35+40+35+45+120 | **630분 ≈ 10.5시간** |
| 실험 · 응용 · 회고 포함 여유 | 각 단원 필수 경로에 이미 e1·응용·필수 회고를 포함. 선택 심화(e2 등)는 단원당 +5~10분 | + 약 100분 |
| 막힘·복습 여유 | 학습자별 | 별도 |

따라서 **하루 과정이 아니라** 5~8회 학습(회당 1.5~2시간)을 권장합니다. 원래 1일 과정에 맞추려고 단원을 줄이지 않았습니다.

## 단원 순서의 이유

1. U01~U03 은 프레임워크 없이 *순수 TypeScript* 로 루프를 만들어 봅니다. 그래야 U04 에서 LangGraph 가 "무엇을 대신해 주는지"가 보입니다.
2. U05 reducer 는 U06 checkpointer 의 선수 개념입니다 (무엇을 저장하는가).
3. U08(중단·재개) → U09(재실행) → U10(중복 방지)은 한 이야기의 세 장입니다. **사고가 나는 것을 먼저 보고** 해법을 배웁니다.
4. U14 는 같은 구조를 *다른 도메인*에서 처음부터 만들게 해 전이를 확인합니다.

## 회상 규칙

- 각 단원의 회상 문제는 직전 단원이 아니라 **2~3단원 전** 개념을 섞습니다.
- U04, U08, U12 직후에는 누적 복습 체크포인트(10분)를 둡니다. (계획)
