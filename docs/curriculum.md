# 제공 범위와 이후 계획

현재 학습 과정은 docs/course의 8개 실습과 최종 실행으로 구성합니다. 시작 주소는 START-HERE.md입니다. 각 챕터에 필요한 설명이 포함되어 있으며 모든 풀이는 터미널에서 코드로 제출합니다.

| 순서 | 실습 | 검사하는 동작 |
|---|---|---|
| 1 | 메시지 객체 | 입력 글과 user 역할 |
| 2 | 기록 배열 | 원본 보존과 새 질문 추가 |
| 3 | await | 비동기 결과와 오류 전달 |
| 4 | 모델 호출 | system → user, 실제 호출 1회 |
| 5 | 대화 초기화 | 새 배열과 서로 독립적인 대화 |
| 6 | 이어 묻기 | 이전 질문·답 전달, 새 답 저장 |
| 7 | 오류 코드 수정 | 답 누락 결함을 실행 검사로 수정 |
| 8 | 사용자별 상태 | 다른 사용자와 서비스의 기록 격리 |
| 최종 | 서비스 대화 | 다른 인원 조건에서 실행 |

이후 도구 호출·반복·LangGraph·상태 저장·승인·재시도·다른 도메인 응용을 확장할 계획입니다. 아직 실행할 단원은 없습니다. 이전 상세 계획은 docs/archive에 보존했습니다.
