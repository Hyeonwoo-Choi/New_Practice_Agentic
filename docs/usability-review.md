# 선형 문제집 사용성 점검

| 사용자 동작 | 현재 설계 |
|---|---|
| 처음 들어오기 | README → START-HERE → 입력 취소 실습 → 1번 문제 |
| 작성할 위치 찾기 | MD에 함수 선언 표시, 터미널 :edit에서 함수 본문만 입력 |
| 필요한 문법 찾기 | 해당 문제 안에서 설명·힌트 제공. 외부 필수 분기 없음 |
| 맞았는지 확인 | :check로 기대 결과와 실제 동작 비교 |
| 틀렸을 때 | 같은 터미널에서 :edit → :save → :check |
| 다음으로 넘어가기 | 통과 후 :next, MD 하단 다음 챕터. 번호·제목 일치 |
| 중단과 복귀 | :quit, 다시 npm run learn. 마지막 저장 위치와 코드 유지 |
| 학습 끝 확인 | 8개 코드 검사 뒤 :run으로 다른 사용자·인원 조건의 대화 실행 |

문서 링크 검사는 현재 경로 밖으로 분기하지 않는지도 확인합니다. 예전 주소는 새 챕터로 연결하는 안내만 남겼습니다. 사용자 작성 기록은 보존했습니다.
