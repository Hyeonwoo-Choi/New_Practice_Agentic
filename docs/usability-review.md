# 첫 학습자 동선 점검

범위: START-HERE → 진단·보충 → U01 → 마무리. 문서·명령 출력·파일 링크를 점검했습니다.

| 끊기던 지점 | 반영한 변경 |
|---|---|
| 처음 열자마자 규칙과 명령이 많고 첫 편집 위치가 불분명 | START-HERE를 폴더 열기·준비·작성 위치·실제 편집 순서로 재구성 |
| 안내 문서에 답이나 코드를 써야 하는지 혼동 | 작성 파일·위치·형식 표, 임시 오류 코드 교체 설명 |
| 진단·보충 뒤 U01로 이동할 링크 부족 | 정답 확인·보충·U01 복귀 링크 추가 |
| 기본 검사 통과 출력이 실험을 건너뛰고 응용으로 안내 | 검사 출력도 실험 → 응용 순서로 수정 |
| 모든 검사 통과 후 다음 행동이 없음 | 회고 → 피드백 → 완료 확인 안내 |
| U02를 지금 시작할 수 있는 듯한 안내 | README와 시작·마무리·커리큘럼에 미제공 상태 명시 |
| 선택 과제 P5 때문에 필수 학습 완료 판단이 어려움 | 마무리에 필수/선택과 진도 표시 의미 설명 |
| view 서버 실행 중 같은 터미널에서 다른 명령을 입력하려 함 | 새 터미널 열기 또는 Ctrl+C 안내 |
| 학습 화면을 파일 편집기로 오해 | 결과 조회와 VS Code 편집의 역할 구분 |

## 남아 있는 확인 사항

- 실제 초보자가 설명만 보고 작업하는 사용자 관찰은 아직 하지 않았습니다. FEEDBACK.md에 막힌 지점을 기록해 확인합니다.
- 학습 화면은 간단한 마크다운 보기이며 코드 파일 편집·이동을 모두 지원하지 않습니다. 이번에는 VS Code에서 파일을 여는 경로를 명시했습니다. 화면 렌더러 자체는 변경하지 않았습니다.
- 진도는 자동 검사와 파일 내용을 표시할 뿐 학습 이해 여부를 판정하지 않습니다.
- U02 이후는 미제공입니다. 이번 변경은 U01 학습 동선을 정리한 것이며 새 단원을 추가하지 않았습니다.
