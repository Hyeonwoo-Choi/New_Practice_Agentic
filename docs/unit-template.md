# 실습 챕터 작성 규격

1. 해결할 문제: 구현할 함수와 요구 동작.
2. 기대 결과: 입력·출력 예와 보존해야 할 조건.
3. 필요한 설명: 이번 문제에 필요한 문법·역할 설명을 본문에 포함.
4. 터미널 작성: 함수 본문만 입력·저장하는 정확한 절차.
5. 자동 검사: 정상 입력 외 변형 입력, 원본 보존, 오류 또는 상태 분리 확인.
6. 실패 수정: 기대·실제 결과를 보고 코드 수정 후 재검사.
7. 통과 후 :next와 MD의 다음 챕터 링크로 같은 단계 이동.

필기 과제는 두지 않습니다. 이전 개념은 결함 수정·다른 조건의 실행 문제로 재사용합니다. 본 경로를 벗어나야만 풀 수 있는 참고 문서를 만들지 않습니다.
