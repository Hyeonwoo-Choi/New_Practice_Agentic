# 진단 문제 정답

풀기 전에 열지 마세요.

| 문제 | 정답 | 한 줄 설명 |
|---|---|---|
| A1 | `네 2` | 배열은 0부터 센다. `list[1]` 은 두 번째, `.content` 는 "네". 길이는 2 |
| A2 | `a` 는 `[1, 2]` 그대로, `b` 는 `[1, 2, 3]` | `[...a, 3]` 은 `a` 를 펼쳐 **새 배열**을 만든다 |
| A3 | **바꾼다** | `push` 는 받은 배열 자체를 고친다. 호출한 쪽의 배열도 바뀐다 |
| B1 | `Promise` 객체 (값 7 이 아님) | `async` 함수는 약속(Promise)을 돌려주고, `await` 가 풀어 준다 |
| B2 | `Promise` | 값을 `return` 해도 Promise 로 감싸진다 |
| B3 | `async` 함수 안, 또는 ES 모듈의 최상위 | 일반 함수 안에서 쓰면 문법 오류 |
| C1 | `JSON.parse(...)` | 반대는 `JSON.stringify(...)` |
| C2 | 응답(response) | 클라이언트(우리 코드)가 요청을 보내면 서버가 응답한다 |
| C3 | 코드는 공유·저장되기 쉬워 키가 새어 나가기 때문 | 환경변수(`.env`)에 두고 코드에는 쓰지 않는다 |
| D1 | `Message[]`: Message 객체들의 배열이라는 타입 표시. `Promise<Turn>`: 나중에 Turn 이 도착한다는 약속 | 타입 표시는 실행에 영향이 없고 편집기가 실수를 알려 준다 |
| D2 | `npm run` 의 옵션이 아니라 **뒤의 값을 스크립트에 넘기라** 는 뜻 | `npm run check -- u01` 의 `u01` 이 스크립트로 전달된다 |
