# U01 마무리 — 끝났는지 확인하고 다음 할 일 정하기

> **지금 하는 일: 완료 확인.** 여기 체크 표시는 본인이 확인하는 용도이며 자동 진도를 바꾸지 않습니다. 새 코드를 작성할 필요는 없습니다.

## 1. 완료 기준 확인

| 확인할 것 | 어디서 확인하나? | 아직 안 했다면 |
|---|---|---|
| 기본 5/5, 응용 2/2 | 터미널: npm run check -- u01 --apply | [구현](05-implement.md) 또는 [응용](07-apply.md)으로 돌아가기 |
| P1~P4에 예상과 이유 작성 | [예측 기록](predictions.md) | 실제로 사전 예상하지 않았다면 사후 작성임을 이유에 표시. 미리 쓴 것처럼 바꾸지 않기 |
| e1 실패 원인을 설명 가능 | [실험](06-experiments.md), 회고 3번 | 실험 기록에서 빠진 메시지 찾기 |
| 필수 회고 1·2·3·5·7 작성 | [회고](reflection.md) | 제목 아래 자리표시 문구를 자기 설명으로 교체 |
| 실제 시간과 불편한 점 기록 | [피드백](FEEDBACK.md) | 본인이 겪은 내용 작성 |

P5와 e2, 회고 4·6은 선택입니다. 진도에 예측 4/5가 표시되어도 P5를 하지 않은 것이라면 필수 과제를 빠뜨린 것은 아닙니다. 힌트나 정답을 봤다는 표시도 실패 판정이 아닙니다.

## 2. 오늘 무엇을 만들었나요?

방 예약 앱 전체를 완성한 것이 아닙니다. **지난 질문과 답을 보관하고, 다음 질문에 함께 보내는 대화 코드**를 만들었습니다. 날짜별 빈방 조회, 도구 실행, 예약 확정은 아직 구현하지 않았습니다.

코드를 닫고 다음을 내 말로 설명해 보세요. 잘 안 되면 괄호 안 문서로 돌아갑니다.

- 답을 받았는데 왜 따로 기록해야 할까? ([개념](03-concept.md))
- 다음 질문의 “그중”은 어떤 메시지를 보고 이해할까? ([예제](04-example.md))
- alice와 bob의 기록을 왜 나눌까? ([응용](07-apply.md))

## 3. 이제 다음에 무엇을 하나요?

**현재 U02 이후는 계획만 있고 실행할 단원은 없습니다.** npm run begin -- u02를 실행하지 마세요. [커리큘럼](../../docs/curriculum.md)은 계획을 보는 참고 자료입니다.

오늘은 여기서 종료해도 됩니다. 더 연습하려면 [자유 연습장](example/scratch.ts)에서 기존 배열을 보존한 채 새 메시지를 추가해 보고, 왜 원본이 유지되는지 설명하세요. 필수 과제는 아닙니다.

AI 튜터와 이어 가고 싶다면 다음처럼 요청하세요. 메시지는 직접 복사해 보내며 자동 전송되지는 않습니다.

> U01을 마쳤어. reflection.md와 FEEDBACK.md를 보고 이해가 부족한 부분을 질문으로 점검해 줘. 새 단원 구현 전에 내가 모르는 부분부터 확인해 줘.

## 4. 종료와 다음번 재개

1. 수정한 파일을 Ctrl+S로 저장하세요.
2. view 서버가 켜져 있다면 해당 터미널에서 Ctrl+C로 종료하세요.
3. 다음번에는 같은 폴더를 열고 npm run status로 진도를 확인하세요. 다시 설치하거나 작업을 초기화할 필요는 없습니다.
4. 모르는 부분이 남았다면 회고의 해당 번호에 적어 두고 다음번에 그 챕터부터 복습하세요.
