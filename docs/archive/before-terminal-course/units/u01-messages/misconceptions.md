각 오해마다 **실행 전에 답하는 예측 질문**이 있습니다. 질문은 `predictions.md` 나 노트에 먼저 답하세요.

## 오해 1. "모델은 우리가 나눈 지난 대화를 기억하고 있다"

- 왜 그렇게 느끼나: ChatGPT 같은 앱은 대화가 이어지는 것처럼 보인다.
- 사실: 앱이 지난 대화를 **매번 다시 보내 주는 것**이다. 모델 호출 자체는 매번 독립이다.
- 예측 질문: *새 대화에서 "그중 가장 저렴한 곳은?" 만 보내면 모델은 어떻게 답할까?* → **P3**
- 확인: `npm run check -- u01` 의 `fresh-no-memory` 실행 기록

## 오해 2. "`chat()` 이 내 messages 배열에 답을 알아서 붙여 준다"

- 왜 그렇게 느끼나: 대화가 쌓이는 것 같은 UI 를 많이 봤기 때문.
- 사실: `chat()` 은 messages 를 **읽기만** 한다. 답을 기록에 붙이는 건 내 코드의 일이다.
- 예측 질문: *04-example 의 마지막 줄 `console.log(messages.length)` 는 몇을 찍을까?* (실행 전에 답하기)
- 확인: `example/ex1-single-call.ts` 실행, 실험 e1

## 오해 3. "system 메시지는 질문할 때마다 다시 넣어야 하고, 넣을수록 좋다"

- 왜 그렇게 느끼나: "매번 보내야 한다" 는 규칙을 system 에도 그대로 적용해서.
- 사실: system 은 대화 기록의 **맨 앞에 한 번**. 기록 전체를 보내므로 이미 포함돼 있다. 질문마다 또 넣으면 기록이 불필요하게 길어지고 모델이 헷갈린다.
- 예측 질문: *질문을 3번 한 뒤 대화 기록에 system 메시지는 몇 개 있어야 할까?* (정답은 시스템 검사 `system-once` 로 확인)
- 확인: `npm run check -- u01` 의 `system-once`
