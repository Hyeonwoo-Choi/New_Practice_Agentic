# 처음 시작하기 — 이 문서부터 순서대로

**코드는 VS Code에서 작성하고, 실행 명령은 터미널에 입력합니다.** 학습 화면은 결과를 보는 곳입니다. 현재 실습할 수 있는 범위는 **기초 보충과 U01**이며 U02 이후는 아직 준비 중입니다.

## 1. 프로젝트 폴더 열기

VS Code에서 File → Open Folder로 이 프로젝트 폴더를 여세요. 왼쪽 탐색기에 package.json과 units 폴더가 보이면 맞는 위치입니다.

이 문서는 Ctrl+Shift+V로 미리보기를 열면 링크를 클릭하며 이동하기 편합니다. 편집 화면의 링크는 마우스를 올려 안내되는 열기 동작(보통 Ctrl+클릭)을 사용하세요.

## 2. 터미널에서 준비하기

상단 Terminal → New Terminal을 열고 아래를 한 줄씩 입력하세요. PS D:…> 같은 프롬프트는 입력하지 않습니다.

```powershell
cd D:\dev\New_Practice_Agentic
node -v
npm install
npm run begin -- u01
```

- node -v는 v22 이상이어야 합니다. node나 npm을 찾을 수 없으면 Node 설치부터 확인하세요.
- npm install은 의존성을 설치합니다. 이미 설치했다면 매번 할 필요는 없습니다.
- begin은 내 코드 폴더 work를 만듭니다. 이미 있으면 보존하며, 학습을 완료해 주지는 않습니다.
- API 키나 .env 설정은 필요 없습니다. 기본은 네트워크 없는 연습용 모델입니다.

## 3. 어디에 무엇을 쓰나요?

| 할 일 | 클릭해서 열 파일 | 작성 위치와 방법 |
|---|---|---|
| 실행 전 예상 | [predictions.md](units/u01-messages/predictions.md) | P1: 뒤에 예상값과 이유. 예: P1: 9 &#124; 이유: 항목이 아홉 개라고 생각해서 (형식 예시이며 정답 아님) |
| 기본 코드 | [work/conversation.ts](units/u01-messages/work/conversation.ts) | TODO(U01-1), TODO(U01-2)를 찾아 함수 안의 임시 오류 코드를 내 코드로 교체 |
| 응용 코드 | [work/apply.ts](units/u01-messages/work/apply.ts) | TODO(U01-3) 주변 구현 |
| 배운 내용 설명 | [reflection.md](units/u01-messages/reflection.md) | 해당 제목 아래 자리표시 문구를 내 문장 2~4개로 교체 |
| 자료에 대한 의견 | [FEEDBACK.md](units/u01-messages/FEEDBACK.md) | 실제 시간 표와 빈 목록에 기록 |

지금 다 채우지 마세요. **각 챕터가 작성할 때를 알려 줍니다.** 예측과 회고는 서로 다른 파일입니다. 안내 .md에 코드를 적어도 검사는 실행하지 않습니다.

## 4. 학습 시작: 아래 다음 챕터부터 따라가기

기초 진단 → 필요한 보충 → U01 소개 → 작성 위치 안내 → 문제 → 문법 → 개념 → 예제 → 예측 → 구현 → 실험 → 응용 → 회고 → 피드백 → 마무리 순서입니다.

각 문서 **맨 아래의 다음 챕터**를 누르세요. 참고 링크는 궁금할 때만 열어도 됩니다. 코드 예제를 열었다면 실행 후 원래 안내 문서로 돌아와 다음 챕터를 누르세요. 문서를 읽는 것과 작성 과제는 상단에서 구분합니다.

## 5. 구현할 차례가 왔을 때의 실제 작업 순서

1. 먼저 예측 파일의 P1·P2·P3을 적고 Ctrl+S로 저장합니다.
2. 구현 안내를 읽고 work/conversation.ts를 엽니다.
3. TODO를 찾아 구현합니다. return notImplemented(...)는 미완성을 알리는 임시 코드이며 실제 반환 코드로 교체합니다. start나 solutions 파일은 수정하지 않습니다.
4. Ctrl+S로 코드를 저장한 뒤 아래 검사 명령을 터미널에 입력합니다.

```powershell
npm run check -- u01
```

처음에는 TODO 때문에 실패하는 것이 정상입니다. 실패한 항목의 고칠 곳과 읽을 곳을 확인하세요. 기본 5/5 통과 뒤에는 오류 실험 챕터로 갑니다. 그 뒤 응용 파일을 구현하고 다음을 실행합니다.

```powershell
npm run check -- u01 --apply
```

기본 5/5와 응용 2/2가 나와도 설명·회고가 남습니다. 전체 완료 기준은 [마무리 안내](units/u01-messages/09-finish.md)에 있습니다.

## 학습 화면은 언제 쓰나요?

```powershell
npm run view
```

터미널에 나온 주소를 열어 실행 기록과 진도를 봅니다. 화면의 문서는 읽기용이며, 파일 작성은 VS Code에서 합니다. 화면에서는 코드 링크가 열리지 않을 수 있으므로 VS Code 탐색기에서 표의 경로를 여세요.

view가 실행 중인 터미널은 서버가 사용하고 있습니다. 검사 명령을 입력하려면 **다른 터미널을 하나 더 열거나**, Ctrl+C로 view를 종료하세요. 종료해도 코드와 기록은 남습니다. 매번 화면을 켤 필요는 없습니다.

## 막히거나 오늘 멈출 때

- 힌트: 터미널에 npm run hint -- u01 1 입력 → 필요하면 2 → 3 순서로 읽고 내 코드로 돌아옵니다.
- 문법 자유 연습: [scratch.ts](units/u01-messages/example/scratch.ts)에 작성합니다. 기본 검사의 대상은 아닙니다.
- 오류 예: --u01이 아니라 **-- u01**입니다. 명령의 -- 앞뒤를 띄우세요.
- 중단: 저장 후 reflection.md의 관련 칸에 모르는 점이나 다음 할 일을 적으세요. 다음번에는 npm run status로 진도를 확인하고 해당 챕터를 다시 엽니다. begin을 다시 해도 기존 작업은 보존됩니다.
- 유지보수용 selftest·lint:units는 학습 과제가 아닙니다. 자기 코드는 check로 검사합니다.
