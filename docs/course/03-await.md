# 3. 늦게 도착하는 결과 기다리기

**문제집 3/8 · 풀이 파일: practice/03-await.ts**

## 해결할 문제

fetchReply()가 돌려주는 Promise를 기다려 메시지를 받고, 메시지 객체가 아닌 답의 글만 반환하세요.

## 나와야 하는 결과

fetchReply가 나중에 { role: "assistant", content: "준비 완료" }를 반환하면 결과는 "준비 완료".

검사는 제시된 예뿐 아니라 다른 입력도 넣습니다. 예시 답을 문자열로 고정해서 반환하면 통과하지 못합니다.

## 이 문제에 필요한 설명

`async` 함수는 나중에 결과가 나오는 Promise를 반환합니다. `await`를 쓰면 그 결과를 받은 뒤 다음 줄을 실행합니다. 이번 함수는 fetchReply를 인자로 받습니다. 호출하려면 fetchReply()처럼 괄호가 필요합니다.

## 터미널에서 작성하기

터미널에는 **3/8 · 늦게 도착하는 결과 기다리기**이 보여야 합니다. 다르면 :back 또는 현재 단계의 :next로 번호를 맞추세요. :next는 현재 단계와 이전 단계 검사를 통과해야 이동합니다.

1. :show로 현재 코드와 작성할 함수를 확인합니다.
2. :edit을 입력합니다. 함수 **안의 코드만** 입력합니다. import, 아래 함수 선언, 함수 바깥 중괄호는 입력하지 않습니다.
3. 여러 줄을 입력해도 됩니다. 입력이 끝나면 별도 줄에 :save를 입력합니다. 이 코드는 기존 함수 본문 전체를 교체합니다.
4. 잘못 입력했다면 저장 전에 :cancel로 취소하고 :edit부터 다시 합니다.

자동으로 제공되는 함수 선언:

```ts
export async function readReply(fetchReply: () => Promise<Message>): Promise<string>
```

작성할 본문의 시작 상태:

```ts
  throw new Error("답을 기다려 글을 반환하세요");
```

위 시작 상태는 미완성 코드입니다. 실제 구현으로 교체해야 합니다. 별도 예상 답안이나 설명문은 작성하지 않습니다.

## 실행하고 점검하기

학습 터미널에서 다음을 입력하세요. PowerShell 명령이 아니라 학습 프로그램의 명령입니다.

```text
:check
```

- 성공: 1번부터 현재 3번까지 ✔가 나옵니다.
- 실패: ✘ 뒤의 기대값·실제값 또는 실패 이유를 읽고 해당 코드를 고칩니다. 이전 단계가 실패했다면 :back으로 돌아가 고친 뒤 다시 순서대로 진행합니다.
- 한 번에 통과하지 않아도 괜찮습니다. **코드 수정 → 저장 → 검사**를 반복합니다.

막히면 이 챕터 안에서 해결할 힌트: const reply = await fetchReply();로 기다린 뒤 reply의 content를 꺼내세요.
