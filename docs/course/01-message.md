# 1. 사용자의 말을 메시지로 만들기

**문제집 1/8 · 풀이 파일: practice/01-message.ts**

## 1. 지금 무엇을 만드나요?

입력한 글에 user라는 이름표를 붙입니다. 이후 모델에 보내는 재료 한 개를 만드는 단계입니다. 아직 AI를 호출하지 않습니다.

**직접 바꿀 코드:** practice/01-message.ts의 작성 구역. 이미 작성한 내용은 자동으로 초기화하지 않습니다.

**입력은 누가 넣나요?** text = "안녕" (함수를 실행하는 검사기가 넣어 줍니다). :check가 함수를 호출하면서 넣어 주므로 사용자가 함수 틀이나 호출 코드를 다시 작성할 필요는 없습니다.

## 2. 해결할 문제와 목표

사용자가 입력한 글을 모델에 전달할 메시지 객체로 바꾸세요. makeMessage(text)를 구현합니다.

makeMessage("안녕") → { role: "user", content: "안녕" }. 다른 글도 그대로 담겨야 합니다.

검사는 제시된 예뿐 아니라 다른 입력도 넣습니다. 예시 답을 문자열로 고정해서 반환하면 통과하지 못합니다.

## 3. 실행해서 차이부터 확인하기

터미널의 단계가 **1/8**인지 확인하고 :check를 입력하세요. 문법·타입 검사 후 함수가 실행됩니다. 시작 코드는 아직 목표 동작을 하지 않으므로 실패하는 것이 정상입니다. 이미 작성한 코드가 통과하면 다음 실험까지 진행하세요.

출력에서 **입력 → 기대 → 실제 → 판정 → 고칠 부분**을 읽으세요. 문법·타입 오류라면 실행 전 작성 구역의 줄 번호와 수정 이유가 나옵니다. 실행 검사에서 실패한 지점 뒤의 검사는 수정 후 다시 수행합니다.

## 4. 이번 문제에 필요한 설명

메시지 하나는 객체입니다. role은 말한 주체를 표시하고 content는 글을 담습니다. 여기서 user는 사용자, assistant는 모델, system은 개발자가 정한 기본 지침입니다. 예를 들어 `{ name: "민수" }`가 이름을 담듯 메시지 객체에는 role과 content를 담습니다.

## 5. 어떤 부분을 어떻게 고치나요?

1. 이번 문제는 터미널 조작을 익히는 따라하기입니다. 먼저 :check를 실행해 기대 content와 실제 content를 비교하세요.
2. content에 고정된 글을 넣으면 어떤 질문에도 같은 글이 나옵니다. 입력 변수 text를 쓰면 입력한 글이 그대로 들어갑니다. text는 변수이고 "text"는 네 글자로 된 고정 문자열입니다.
3. 이 문제에서 바꿀 곳은 content 값 하나입니다. 아래 따라하기 명령으로 1번 줄을 교체합니다.

**자동 제공되는 함수 틀(입력하지 않음):** `export function makeMessage(text: string): Message`. 이 틀 안의 작성 구역만 편집합니다. 아래가 새 파일의 작성 구역 시작 상태입니다. 이미 작성했다면 :show에 나온 현재 줄을 기준으로 수정하세요.

```ts
  return { role: "user", content: "연습" };
```

**첫 문제 따라하기:** 아래를 학습 터미널에 입력하세요. 함수 선언을 복사하는 것이 아니라 1번 줄의 실행 코드만 교체합니다.

```text
:edit
:set 1 return { role: "user", content: text };
:save
```


저장하기 전에는 :list로 줄 번호와 내용을 확인하고, 잘못 고쳤다면 :undo로 마지막 편집을 되돌릴 수 있습니다. :cancel은 이번 편집 전체를 취소합니다. 번호와 │ 표시는 코드에 입력하지 않습니다.

## 6. 저장·검사 결과를 확인하기

:save를 입력하면 문법·타입 검사 → 저장된 코드 표시 → 자동 실행 검사가 이어집니다. 문법·타입이 틀리면 기존 파일을 바꾸지 않고 편집 상태로 남습니다. 출력된 줄을 :set으로 고치고 다시 :save하세요.

정상 저장 뒤에도 동작이 다르면 **수정 필요**가 표시됩니다. 실제 값이 기대와 어떻게 다른지 확인하고 :edit로 다시 고칩니다. :check는 저장한 코드를 언제든 다시 검사합니다.

성공하면 입력 "안녕"에는 content "안녕", 다른 입력에는 그 입력한 글, 빈 입력에는 빈 글이 나옵니다. 모두 일치해야 첫 문제를 통과합니다.

막히면 이 챕터 안에서 해결할 힌트: 객체는 { 속성: 값 }입니다. role은 "user", content는 인자로 받은 text입니다.

## 7. 다른 입력으로 직접 실행하기

```text
:try 내가 입력한 다른 글
```

직접 입력한 글이 함수에 전달됩니다. 실제 반환값을 확인하세요. :try는 결과를 관찰하는 실험이고 통과 판정은 :check가 담당합니다. 별도 필기는 없습니다.

## 8. 다음 단계로 이동

검사가 통과하면 :next를 입력합니다. 현재와 이전 코드들을 재검사한 뒤 다음 단계로 이동합니다. 이전 단계가 실패하면 해당 번호까지 :back으로 돌아가 수정하세요. 터미널에 다음 단계가 표시되면 아래 링크를 누릅니다. 마지막 실습에서는 “모든 실습을 통과했습니다”가 표시됩니다.
