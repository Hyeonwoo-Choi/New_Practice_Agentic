# 9. 완성한 서비스 실행하기

## 해결할 문제

8단계에서 만든 서비스가 다른 사용자와 다른 인원 조건에서도 동작하는지 실제 대화로 확인합니다. 별도 필기나 회고는 없습니다.

## 기대 결과

| 순서 | 입력 | 기대하는 결과 |
|---|---|---|
| 1 | alice: 4명이 쓸 방 찾아 줘 | 4명 이상 방 목록 |
| 2 | bob: 그중 가장 저렴한 곳은? | 이전 목록을 찾을 수 없다고 응답 |
| 3 | alice: 그중 가장 저렴한 곳은? | R-102 |
| 4 | bob: 6명이 쓸 방 찾아 줘 | 6명 이상 방 목록 |
| 5 | bob: 그중 가장 저렴한 곳은? | R-201 |

## 실행하고 점검하기

8번 실습을 통과한 뒤 :next를 입력해 “모든 실습을 통과했습니다”가 표시된 상태에서 아래를 입력하세요.

```text
+:run
+```

전체 검사를 다시 돌리고 직접 작성한 서비스로 위 5개 대화를 실행합니다. 출력과 표를 비교하세요. 실패하면 표시된 단계로 :back을 이용해 돌아가 고친 뒤 순서대로 검사하세요. 완료 여부는 작성한 글의 유무가 아니라 코드가 이 동작을 하는지로 판단합니다.

## 오늘 만든 것과 다음 할 일

메시지 객체, 대화 기록, 모델 호출, 사용자별 대화 분리를 구현했습니다. 실제 빈방 조회·예약은 아직 하지 않습니다. U02 이후는 제공되지 않으므로 여기서 더 넘어갈 실습은 없습니다.

최종 실행이 성공했다면 :quit으로 종료하세요. 다음번 npm run learn을 실행하면 완료 상태로 돌아옵니다. 복습은 :back으로 이전 단계에 돌아가 코드를 바꿔 다시 검사하면 됩니다. 변경한 코드는 이후 단계와 함께 다시 검사합니다.
