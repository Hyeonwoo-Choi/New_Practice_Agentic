# 0. 작성 화면과 실행 화면 익히기

## 이번에 할 일

기존 코드를 지우지 않고 **작성한 줄 보기 → 한 줄 수정 → 되돌리기 → 취소**를 직접 해 봅니다. 저장·정답 검사는 다음 1번 문제에서 합니다.

## 1. 현재 코드와 상태 확인

학습 터미널에 입력합니다. 학습 프로그램이 꺼져 있다면 프로젝트 폴더에서 npm run learn으로 시작하세요.

```text
:show
:check
```

화면에서 “이번에 만드는 기능”, 입력, 기대 결과와 작성 구역을 확인합니다. :check는 먼저 문법·타입을 확인하고, 정상 코드라면 실제 입력을 넣어 실행합니다. 아직 미완성 코드이므로 실패해도 정상입니다. 이미 작성한 코드가 있다면 그 코드를 검사합니다.

문법 오류가 나오면 “고칠 위치”를, 실행 결과가 다르면 “입력·기대·실제·고칠 부분”을 봅니다. 해결은 다음 챕터에서 합니다.

## 2. 저장하지 않고 줄 편집 연습

아래를 한 줄씩 입력하세요.

```text
:edit
:list
:set 1 // 편집 조작을 연습하는 임시 줄
:list
:undo
:list
:cancel
:show
```

**기대 결과:** :set 뒤에는 1번 줄이 임시 주석으로 바뀌고, :undo 뒤에는 원래 줄로 돌아옵니다. :cancel 뒤에도 저장 파일은 원래 그대로입니다. 이 연습에서는 :save를 입력하지 않습니다.

화면의 줄 번호와 │는 입력하지 않습니다. :set 1 뒤에 작성할 코드만 넣습니다. 여러 줄 함수도 한 줄씩 고칠 수 있습니다.

## 3. 다음 문제에서 사용할 작업 순서

| 상태 | 할 일 | 확인할 결과 |
|---|---|---|
| 실습 화면 | :check | 현재 코드의 입력·기대·실제·판정 |
| 편집 화면 진입 | :edit | 기존 코드가 줄 번호와 함께 표시됨 |
| 한 줄 수정 | :set 줄번호 코드 | 변경된 줄 미리보기 |
| 줄 추가·삭제 | :insert 줄번호 코드 / :delete 줄번호 | 다른 줄은 유지됨 |
| 잘못 편집 | :undo | 마지막 편집 되돌림 |
| 여러 줄 전체 교체 | :paste → 코드 입력 → :done | 저장 전 전체 미리보기 |
| 저장·자동 검사 | :save | 문법·타입 검사 → 저장 코드 → 입력별 실행 결과 |
| 추가 실험 | :try 내가 넣을 글 | 그 글을 넣었을 때의 실제 반환값 |
| 다음 단계 | :next | 전체 재검사 통과 후 다음 문제 표시 |

함수 이름과 입력 변수, import는 제공됩니다. **함수 선언을 다시 입력하지 않습니다.** 1번 문제에서는 한 줄을 바꾸는 명령을 따라 하며 이 구분을 익힙니다.

문법·타입이 틀리면 저장되지 않고 편집 화면에 남습니다. 해당 줄을 :set으로 고친 뒤 :save하세요. 저장 후 실행 결과가 다르면 파일은 저장된 상태이고, :edit로 다시 열어 고칩니다.

종료는 :quit, 재시작은 일반 터미널에서 npm run learn입니다. 저장 전 입력은 종료하면 취소되고 저장한 코드는 유지됩니다.

**터미널은 1/8에 둔 채 다음 MD를 여세요. 지금은 아직 :next를 입력하지 않습니다.**
