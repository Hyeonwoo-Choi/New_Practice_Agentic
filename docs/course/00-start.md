# 0. 터미널에서 코드 입력 연습

## 해결할 문제

코드 입력 모드에 들어갔다가 취소해서 기존 파일이 보존되는지 확인합니다. 제출할 설명은 없습니다.

## 기대 결과

취소한 코드는 파일에 저장되지 않고 원래 시작 코드가 그대로 표시됩니다.

## 직접 실행

학습 터미널에 아래를 한 줄씩 입력하세요. 학습 터미널이 꺼졌다면 프로젝트 폴더에서 npm run learn으로 시작하세요.

```text
:show
:edit
// 입력을 취소하는 연습입니다.
:cancel
:show
```

위 명령을 한 줄씩 입력하세요. 마지막 :show에서 원래 코드가 유지되는지 확인하세요. 이 준비 단계는 실습 진도를 이동하지 않습니다.

## 앞으로 코드를 작성하는 방법

각 문제에 함수 이름과 입력이 제공됩니다. :edit을 누른 뒤에는 **그 함수 안의 코드만** 입력하고, 별도 줄에 :save를 입력합니다. 기존 함수 본문 전체가 새 입력으로 바뀝니다. 함수 선언·import·함수 바깥 중괄호는 프로그램이 붙여 줍니다.

예를 들어 함수가 “숫자 7 반환”을 요구했다면 입력은 아래처럼 합니다. 실제 1번 문제의 정답은 아닙니다. 지금 실행할 필요는 없습니다.

```text
:edit
return 7;
:save
:check
```

저장 전 취소는 :cancel입니다. 저장한 이전 버전은 practice/.backups에 남습니다. 종료하려면 :quit, 다시 시작하려면 일반 터미널에서 npm run learn입니다. 저장하지 않고 종료한 입력은 버려집니다.

검사가 실패하면 :show → :edit → 코드 입력 → :save → :check를 반복합니다. MD의 힌트와 터미널 :hint는 같은 내용을 보여 주므로 별도 페이지로 이동하지 않습니다.

**이제 1번 문제를 엽니다. 터미널에서는 아직 :next를 누르지 마세요.** 1번 문제 코드를 구현하고 검사한 다음 이동합니다.
