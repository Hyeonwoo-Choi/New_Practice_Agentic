# 8. 두 사용자의 대화 분리하기

**문제집 8/8 · 풀이 파일: practice/08-users.ts**

## 해결할 문제

alice와 bob이 번갈아 질문합니다. 사용자 ID별로 기록을 저장하는 서비스를 만드세요. newConversation과 ask는 앞 단계에서 작성한 함수를 가져왔습니다. 서비스마다 보관함도 독립적이어야 합니다.

## 나와야 하는 결과

alice: 4명 방 추천 → 목록. bob: 그중 싼 곳? → 대화에서 찾을 수 없음. alice: 그중 싼 곳? → R-102. 새 서비스도 이전 대화를 몰라야 함.

검사는 제시된 예뿐 아니라 다른 입력도 넣습니다. 예시 답을 문자열로 고정해서 반환하면 통과하지 못합니다.

## 이 문제에 필요한 설명

Map은 사용자 ID로 값을 넣고 꺼내는 저장소입니다. `const prices = new Map<string, number>(); prices.set("apple", 100); prices.get("apple");`의 결과는 100, 없는 키는 undefined입니다. 이번 값은 숫자가 아니라 Message[]입니다. 사용자별 Map은 createChatService 안, say 밖에 두어야 같은 서비스의 다음 호출에도 유지됩니다.

## 터미널에서 작성하기

터미널에는 **8/8 · 두 사용자의 대화 분리하기**이 보여야 합니다. 다르면 :back 또는 현재 단계의 :next로 번호를 맞추세요. :next는 현재 단계와 이전 단계 검사를 통과해야 이동합니다.

1. :show로 현재 코드와 작성할 함수를 확인합니다.
2. :edit을 입력합니다. 함수 **안의 코드만** 입력합니다. import, 아래 함수 선언, 함수 바깥 중괄호는 입력하지 않습니다.
3. 여러 줄을 입력해도 됩니다. 입력이 끝나면 별도 줄에 :save를 입력합니다. 이 코드는 기존 함수 본문 전체를 교체합니다.
4. 잘못 입력했다면 저장 전에 :cancel로 취소하고 :edit부터 다시 합니다.

자동으로 제공되는 함수 선언:

```ts
export function createChatService(): { say(userId: string, question: string): Promise<string> }
```

작성할 본문의 시작 상태:

```ts
  throw new Error("사용자별로 기록을 나누는 서비스를 반환하세요");
```

위 시작 상태는 미완성 코드입니다. 실제 구현으로 교체해야 합니다. 별도 예상 답안이나 설명문은 작성하지 않습니다.

## 실행하고 점검하기

학습 터미널에서 다음을 입력하세요. PowerShell 명령이 아니라 학습 프로그램의 명령입니다.

```text
:check
```

- 성공: 1번부터 현재 8번까지 ✔가 나옵니다.
- 실패: ✘ 뒤의 기대값·실제값 또는 실패 이유를 읽고 해당 코드를 고칩니다. 이전 단계가 실패했다면 :back으로 돌아가 고친 뒤 다시 순서대로 진행합니다.
- 한 번에 통과하지 않아도 괜찮습니다. **코드 수정 → 저장 → 검사**를 반복합니다.

막히면 이 챕터 안에서 해결할 힌트: 함수 안에 Map<string, Message[]>를 만들고, { async say(userId, question) { ... } }를 반환하세요. get으로 조회하고 없으면 새 대화. ask 뒤 set으로 갱신하고 answer 반환. Map은 say 밖에 둡니다.
