# 7. 답을 잃어버리는 코드 고치기

**문제집 7/8 · 풀이 파일: practice/07-repair.ts**

## 해결할 문제

아래 코드는 첫 답을 보여 주지만 다음 질문에 실패합니다. 실행 검사로 원인을 확인하고 함수를 고치세요. 별도의 설명문은 작성하지 않습니다.

## 나와야 하는 결과

반환 기록의 마지막은 assistant. 이어서 "그중 가장 저렴한 곳은?"을 물어도 추천 목록을 이해해야 함.

검사는 제시된 예뿐 아니라 다른 입력도 넣습니다. 예시 답을 문자열로 고정해서 반환하면 통과하지 못합니다.

## 이 문제에 필요한 설명

이번에는 새 함수를 처음부터 만드는 대신 주어진 결함을 고칩니다. 첫 질문의 화면 출력만 정상이어도 후속 질문은 실패할 수 있습니다. 검사는 답의 문구뿐 아니라 반환한 기록과 실제 모델에 전달된 메시지 순서를 확인합니다.

## 터미널에서 작성하기

터미널에는 **7/8 · 답을 잃어버리는 코드 고치기**이 보여야 합니다. 다르면 :back 또는 현재 단계의 :next로 번호를 맞추세요. :next는 현재 단계와 이전 단계 검사를 통과해야 이동합니다.

1. :show로 현재 코드와 작성할 함수를 확인합니다.
2. :edit을 입력합니다. 함수 **안의 코드만** 입력합니다. import, 아래 함수 선언, 함수 바깥 중괄호는 입력하지 않습니다.
3. 여러 줄을 입력해도 됩니다. 입력이 끝나면 별도 줄에 :save를 입력합니다. 이 코드는 기존 함수 본문 전체를 교체합니다.
4. 잘못 입력했다면 저장 전에 :cancel로 취소하고 :edit부터 다시 합니다.

자동으로 제공되는 함수 선언:

```ts
export async function ask(history: Message[], question: string): Promise<{ messages: Message[]; answer: string }>
```

작성할 본문의 시작 상태:

```ts
  const messages: Message[] = [...history, { role: "user", content: question }];
  const reply = await chat(messages);
  return { messages, answer: reply.content };
```

위 시작 상태는 일부러 결함이 있는 코드입니다. 원인을 고쳐야 합니다. 별도 예상 답안이나 설명문은 작성하지 않습니다.

## 실행하고 점검하기

학습 터미널에서 다음을 입력하세요. PowerShell 명령이 아니라 학습 프로그램의 명령입니다.

```text
:check
```

- 성공: 1번부터 현재 7번까지 ✔가 나옵니다.
- 실패: ✘ 뒤의 기대값·실제값 또는 실패 이유를 읽고 해당 코드를 고칩니다. 이전 단계가 실패했다면 :back으로 돌아가 고친 뒤 다시 순서대로 진행합니다.
- 한 번에 통과하지 않아도 괜찮습니다. **코드 수정 → 저장 → 검사**를 반복합니다.

막히면 이 챕터 안에서 해결할 힌트: answer에 글을 넣는 것과 messages에 메시지 객체를 넣는 것은 다릅니다. 반환하는 messages를 살펴보세요.

## 다음 단계로 이동

검사가 통과하면 터미널에서 :next를 입력합니다. 다음 단계가 표시되면 아래 링크를 누르세요. 마지막 실습에서는 “모든 실습을 통과했습니다”가 표시됩니다.
