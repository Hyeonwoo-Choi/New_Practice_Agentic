# 2. 원본을 보존하며 질문 추가하기

**문제집 2/8 · 풀이 파일: practice/02-history.ts**

## 해결할 문제

기존 메시지 배열 뒤에 새 사용자 메시지를 붙인 새 배열을 반환하세요. 원래 배열은 바꾸지 않습니다.

## 나와야 하는 결과

기존 1개 + 질문 → 새 배열 2개. 원래 배열은 1개 그대로. 빈 배열 + 질문 → 1개.

검사는 제시된 예뿐 아니라 다른 입력도 넣습니다. 예시 답을 문자열로 고정해서 반환하면 통과하지 못합니다.

## 이 문제에 필요한 설명

`push`는 기존 배열을 바꿉니다. `[...old, newItem]`은 기존 내용을 펼쳐 새 배열을 만듭니다. 예를 들어 `[...[1, 2], 3]`은 `[1, 2, 3]`입니다. 이번 과제에서는 전달받은 history를 바꾸면 실패합니다.

## 터미널에서 작성하기

터미널에는 **2/8 · 원본을 보존하며 질문 추가하기**이 보여야 합니다. 다르면 :back 또는 현재 단계의 :next로 번호를 맞추세요. :next는 현재 단계와 이전 단계 검사를 통과해야 이동합니다.

1. :show로 현재 코드와 작성할 함수를 확인합니다.
2. :edit을 입력합니다. 함수 **안의 코드만** 입력합니다. import, 아래 함수 선언, 함수 바깥 중괄호는 입력하지 않습니다.
3. 여러 줄을 입력해도 됩니다. 입력이 끝나면 별도 줄에 :save를 입력합니다. 이 코드는 기존 함수 본문 전체를 교체합니다.
4. 잘못 입력했다면 저장 전에 :cancel로 취소하고 :edit부터 다시 합니다.

자동으로 제공되는 함수 선언:

```ts
export function appendQuestion(history: Message[], text: string): Message[]
```

작성할 본문의 시작 상태:

```ts
  throw new Error("새 배열을 반환하세요");
```

위 시작 상태는 미완성 코드입니다. 실제 구현으로 교체해야 합니다. 별도 예상 답안이나 설명문은 작성하지 않습니다.

## 실행하고 점검하기

학습 터미널에서 다음을 입력하세요. PowerShell 명령이 아니라 학습 프로그램의 명령입니다.

```text
:check
```

- 성공: 1번부터 현재 2번까지 ✔가 나옵니다.
- 실패: ✘ 뒤의 기대값·실제값 또는 실패 이유를 읽고 해당 코드를 고칩니다. 이전 단계가 실패했다면 :back으로 돌아가 고친 뒤 다시 순서대로 진행합니다.
- 한 번에 통과하지 않아도 괜찮습니다. **코드 수정 → 저장 → 검사**를 반복합니다.

막히면 이 챕터 안에서 해결할 힌트: [...history, 새객체]는 history의 내용을 펼친 뒤 새 객체를 추가한 배열입니다.
