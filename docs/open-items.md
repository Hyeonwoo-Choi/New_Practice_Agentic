# 현재 한계와 검증 범위

- 제공된 실습은 기초와 대화 관리 8단계, 최종 서비스 실행까지입니다. 이후 도구·LangGraph 단원은 아직 없습니다.
- 새 학습 경로는 MD 문제집 + npm run learn입니다. npm run view와 기존 begin/check/experiment/solution은 이전 units 작업을 위한 호환 도구이며 새 practice 과정의 진도를 나타내지 않습니다.
- 터미널 편집기는 함수 본문을 여러 줄 입력해 교체하는 방식입니다. 커서 이동·줄 단위 수정 기능은 없습니다. 취소 후 다시 입력하거나 저장 파일을 편집할 수 있습니다. 저장 직전 버전은 practice/.backups에 보존됩니다.
- 실습 검사는 15초 안에 끝나야 합니다. 무한 반복이나 끝나지 않는 Promise는 시간 초과로 실패합니다.
- 키와 네트워크 없이 fake 모델만 사용합니다. 실제 모델 연결은 이번 경로의 학습 과제가 아닙니다.
- 자동 검사는 동작을 점검합니다. 실제 초보자가 문제 설명만 보고 끝까지 푸는 사용성 관찰은 아직 필요합니다.
- 문서 구조·실습 검사·입력 취소·저장·문법 오류 후 수정·진도 이동·재시작·최종 대화를 자동 검증합니다. 별도의 사용자 터미널에서 수동으로 전체 문제를 푼 것은 아닙니다.
- 기존 코드와 학습 진도는 유지하고, 교체된 MD의 이전 내용은 docs/archive/before-terminal-course에 복사해 보존합니다.
